# Linux File Permissions Security Audit

## Project Overview
This project focuses on auditing and correcting file permissions in a Linux environment to ensure secure access control. The task involved identifying misconfigured permissions and modifying them to follow the **principle of least privilege**, ensuring that only authorized users can access or modify sensitive files.

## Objective
The objective of this project was to analyze existing file and directory permissions and correct security risks caused by overly permissive access settings.

## What I Did
- Audited file and directory permissions in a Linux system
- Identified files with insecure permission settings
- Modified permissions to remove unnecessary access rights
- Restricted access to sensitive files and directories
- Verified all changes after applying security controls

## Tools & Technologies
- Linux Terminal
- Bash commands
- chmod
- ls

## Skills Gained
- Linux system administration
- File permission management
- Security auditing
- Access control implementation
- Applying the principle of least privilege

## Outcome
After auditing and updating the permissions, sensitive files and directories were properly secured. Unauthorized modification rights were removed, improving overall system security and enforcing controlled access to project data.

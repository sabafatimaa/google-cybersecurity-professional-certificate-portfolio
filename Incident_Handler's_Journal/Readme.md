# Incident Handlers Journal

A collection of incident response investigations and hands-on security analysis completed as part of my cybersecurity training. This journal documents multiple real-world security scenarios, demonstrating the structured approach used by security analysts to identify, investigate, analyze, and document cybersecurity incidents.

The activities follow industry-standard incident handling practices and emphasize technical analysis, incident documentation, and evidence-based decision making.

---

## Project Overview

This journal contains six incident handling exercises covering different types of cybersecurity incidents, including phishing attacks, ransomware, malware analysis, network traffic investigation, intrusion detection, and data breaches.

Each journal entry documents:

- Incident description
- The 5 W's (Who, What, When, Where, Why)
- Investigation process
- Security tools used
- Indicators of Compromise (IoCs)
- Findings and recommendations
- Lessons learned

The report demonstrates the ability to investigate security events, analyze evidence, document findings, and recommend appropriate mitigation strategies.
